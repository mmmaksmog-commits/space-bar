# 🍸 Космический бар

**Игра на скорость: смешивайте коктейли для инопланетян по рецептам.**

### ▶️ [Играть](https://mysik-portfolio.vercel.app/space-bar/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- Гости с заказами и шкалой терпения
- Коктейль собирается слоями в правильном порядке
- Чаевые зависят от скорости, сложность растёт
- Смена 90 секунд и рекорд

## Стек

JavaScript, requestAnimationFrame. Один файл `index.html`, без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/space-bar.git
cd space-bar
python3 -m http.server 8000
```
